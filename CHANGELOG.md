# Changelog

## 0.1.0

- First release: destination search with inn suggestions, mage-only `/who`, batch ask
  with cooldowns, explain follow-up, port partner tracking with a one-click Port button,
  scroll and rested status, world map inn icons, minimap button, enUS/deDE localization.
- Search results list the mages inside the chosen town first, then the rest of the zone.
- Themed scrollbar for the result list; full scroll name in the status line.
